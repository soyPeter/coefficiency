# Code Review

Cross-language code review patterns for identifying quality issues, security vulnerabilities, and best practices.

## Overview

This skill provides comprehensive code review patterns applicable across any programming language, focusing on quality, security, and maintainability.

## Key Topics

- **Code quality** - Logic correctness, error handling, resource management
- **Security review** - Input validation, SQL injection, secrets management
- **Performance** - N+1 queries, memory leaks, algorithmic efficiency
- **Design patterns** - SOLID, DRY, proper abstractions
- **Test review** - Test quality, edge cases, coverage
- **Language-specific** - Java, Python, Go, TypeScript patterns

## Usage

Use this skill when:
- Reviewing pull requests
- Conducting code quality assessments
- Setting up review standards
- Performing security-focused reviews
