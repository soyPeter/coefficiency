# DevOps Patterns

Production-grade DevOps patterns covering CI/CD, Infrastructure as Code, monitoring, and platform engineering.

## Overview

This skill covers DevOps best practices for production environments including pipeline automation, IaC templates, observability setup, and incident response.

## Key Topics

- **CI/CD pipelines** - GitHub Actions, GitLab CI, automated testing and deployment
- **Infrastructure as Code** - Terraform modules, Kubernetes IaC, state management
- **Monitoring** - SLI/SLO definitions, Prometheus alerts, dashboards
- **GitOps** - ArgoCD workflows, declarative deployments
- **Platform engineering** - Self-service portals, golden paths
- **Incident response** - Runbooks, rollback procedures

## Usage

Use this skill when:
- Setting up or optimizing CI/CD pipelines
- Building Infrastructure as Code templates
- Establishing monitoring and alerting
- Implementing GitOps workflows
- Creating self-service developer platforms
