# Frontend Slides Creation

Create animation-rich HTML presentations for talks, pitches, and demos.

## Quick Reference

| Tool | Use Case |
|------|----------|
| **Reveal.js** | HTML presentations with animations |
| **Remotion** | Video-like presentations |
| **Slidev** | Developer-focused slides |
| **Converters** | PPT/PPTX to HTML |

## Workflow
1. Design in PowerPoint/Keynote (optional)
2. Convert or build with HTML/CSS
3. Add animations with Reveal.js
4. Export or present live

## Best Practices
- Keep slides simple
- Use animations sparingly
- Ensure readability
- Test on projection
