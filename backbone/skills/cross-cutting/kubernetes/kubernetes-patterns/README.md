# Kubernetes Patterns

Production-grade Kubernetes patterns for cluster design, workload deployment, and security hardening.

## Overview

This skill covers Kubernetes best practices for production environments including cluster architecture, deployment patterns, RBAC configuration, and GitOps workflows.

## Key Topics

- **Cluster architecture** - Production-grade cluster design with quotas and limit ranges
- **Workload deployment** - Deployments, HPA, PDB, andPod patterns
- **Security hardening** - Pod Security Standards, RBAC, network policies
- **GitOps** - ArgoCD application definitions and Helm charts
- **Service mesh** - Istio traffic management basics
- **Troubleshooting** - Common K8s issues and diagnostics

## Usage

Use this skill when:
- Designing Kubernetes cluster architecture
- Deploying applications to Kubernetes
- Configuring RBAC and security policies
- Setting up GitOps workflows
- Troubleshooting K8s issues
